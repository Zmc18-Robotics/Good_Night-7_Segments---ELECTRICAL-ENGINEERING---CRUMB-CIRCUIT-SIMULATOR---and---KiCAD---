# Description

Some 7 Segments used in this project, and some LED's art, showed "Good Night" and Moon Art LED

used to be the knowledge of 7 Segments systems, Seems complex but it's actually easy, It's just LED but it in the box of Numbers / Alphabet. Make sure the voltage is 5.4V

Here the materials :
- Breadboard x8
- Arduino Nano x1
- LED pin x121
- Resistor 220Ω x10
- Resistor 40Ω x2
- Resistor 10000Ω x1
- SPST Switch x1
- Power Supply x1
- Capacitor 33µF x1
